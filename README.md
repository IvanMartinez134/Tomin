# 🏦 Tomin - DeFi Savings Platform

> **Una plataforma de ahorro que conecta usuarios con DeFindex CETES en Stellar**

## 🚀 Inicio Rápido

```bash
# 1. Backend
cd backend
npm install
npm start     # http://localhost:3001

# 2. Frontend
cd savings-boxes-app
npm install
npm run dev   # http://localhost:5173

# 3. Smart Contracts
cd tomin-contracts
stellar contract build
```
